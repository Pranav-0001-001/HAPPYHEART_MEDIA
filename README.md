# HAPPY HEART MEDIA Official Website
> *"Websites That Work. Ads That Grow."*

Welcome to the official, multi-page freelance agency website for **HAPPY HEART MEDIA**. 

Built with an attractive, modern **Light Theme**, the official brand emblem is integrated as both the primary logo and the ambient website background watermark. It features a streamlined client work intake portal where clients can submit their tasks for execution, direct WhatsApp delivery, and full Instagram integration (`@HAPPYHEART_MEDIA`).

---

## 🌟 Pages & Architecture

1. [`index.html`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/index.html) — **Home**:
   - Clean, welcoming hero with official logo emblem showcase.
   - Core value proposition ("Websites That Work. Ads That Grow.").
   - 3-pillar services overview and 3-step "How It Works" workflow.
   - Instagram spotlight with link to `@HAPPYHEART_MEDIA`.

2. [`services.html`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/services.html) — **Services & Pricing**:
   - Transparent pricing tiers for Website Development ($399, $799, $1,399), Ads & Marketing ($450, $750, $1,200), and Full Growth Suite ($1,499).
   - "Delegate Work" buttons with automatic service pre-selection on the intake form.

3. [`submit-work.html`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/submit-work.html) — **Give Us Work (Client Work Portal)**:
   - Simple, structured 3-step project intake form:
     1. Choose Service Category (Web Development, Ads, Full Growth Suite, Branding, Custom).
     2. Scope & Timeline (Rush 3-5 days, Standard 1-2 weeks, Flexible), budget brackets, reference links.
     3. Client Contact Details (Name, Brand, Email, WhatsApp).
   - **Instant Tracking ID**: Generates reference numbers like `HHM-2026-8941`.
   - **1-Click WhatsApp Delivery**: Pre-fills the entire formatted brief ready to send to your team with one tap.
   - **Downloadable Brief**: Download project specs as a `.txt` file.

4. [`portfolio.html`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/portfolio.html) — **Portfolio & Case Studies**:
   - Filterable gallery (All, Websites, Ads & Marketing, Branding).
   - Real-world case studies with quantifiable client metrics (+218% mobile conversions, 4.8x ROAS).

5. [`contact.html`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/contact.html) — **Contact & FAQ**:
   - Direct communication channels: WhatsApp direct chat, Instagram DM (`@HAPPYHEART_MEDIA`), and email.
   - Expandable FAQ accordion addressing timelines, revisions, payments, and deliverables.

## 🎨 Design & Aesthetic

- **Theme**: Clean, attractive pearl-white light mode with dark charcoal slate typography (`#0f172a`, `#334155`) for effortless readability.
- **Background**: The official HAPPY HEART MEDIA logo is integrated as a fixed background watermark with an ambient radial light wash across all pages.
- **Accents**: Metallic gold gradients (`#d4af37` to `#b8860b`) and official Instagram gradients.
- **Client Portal**: Sticky drawer accessible across all pages with an active submission counter.

## 🚀 How to Launch & Preview

### Instant Double-Click:
- Double-click [`start.bat`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/start.bat) or open [`index.html`](file:///c:/Users/prana/OneDrive/Documents/HAPPYHEART_MEDIA/index.html) in your browser.

### Run Local Node Server:
```bash
npm start
# Opens local HTTP server on http://localhost:3000
```

### Run Python Server:
```bash
python -m http.server 3000
# Visit http://localhost:3000
```
